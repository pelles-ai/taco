## A minimal sub agent

A working subcontractor agent is under 30 lines of code. Declare your trade, advertise the skills you support, register a handler — done.

```python
from taco import (
    A2AServer, Artifact, ConstructionAgentCard,
    ConstructionSkill, Task, make_artifact, make_data_part,
)

card = ConstructionAgentCard(
    name="PipeWorks Mech Estimator",
    trade="mechanical",
    csi_divisions=["22", "23"],
    integrations=["procore", "acc"],
    skills=[
        ConstructionSkill(
            id="estimate",
            task_type="estimate",
            input_schema="bom-v1",
            output_schema="estimate-v1",
        ),
    ],
)

server = A2AServer(card.to_a2a())

async def handle_estimate(task: Task, bom: dict) -> Artifact:
    # Your estimator logic — LLM, spreadsheet model, internal API
    total = sum(li["quantity"] * 22.50 for li in bom["lineItems"])
    return make_artifact(
        parts=[make_data_part({
            "projectId": bom["projectId"],
            "currency": "USD",
            "summary": {"total": round(total, 2)},
            "metadata": {"generatedBy": "pipeworks-est-v2"},
        })],
        name="estimate-result",
    )

server.register_handler("estimate", handle_estimate)
```

Wire it to a real estimating engine, register with the GC's project registry, and your shop is in the discovery layer for every TACO-aware GC.

## How to start

1. **Build a stub.** Follow [Build a Custom Agent](/docs/getting-started/build-agent) — replace the handler body with a no-op that returns canned data.
2. **Wire it to your real estimator.** Whether that's an LLM call, an internal API, or a spreadsheet model — same handler shape.
3. **Publish your Agent Card.** Once it's live at a stable URL, any GC's registry can discover it.
4. **Tell your repeat-business GCs.** They'll know what to do with a TACO endpoint once they have one.
